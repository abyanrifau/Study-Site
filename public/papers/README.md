# Put your past paper PDFs in this folder

Naming format:

    UNIT_YEAR_SERIES_TYPE.pdf

- UNIT    WBS11, WBS12, WBS13, WBS14, WAC12, WEC14
- YEAR    four digits, e.g. 2024
- SERIES  Jan, Jun (May/June), Oct (October/November)
- TYPE    QP (question paper), MS (mark scheme), ER (examiner report)

Examples:

    WBS11_2024_Jun_QP.pdf
    WBS11_2024_Jun_MS.pdf
    WBS11_2024_Jun_ER.pdf
    WAC12_2023_Oct_QP.pdf

No sub-folders. Capital letters do not matter. Refresh the Papers page after adding files.
